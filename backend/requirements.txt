# When a MinerU read fails/empties, backend/ocr_gpu_worker.py OCRs the crop on the
# GPU. It must NOT be installed into THIS venv: paddlepaddle-gpu ships the same
# cuDNN/cuBLAS DLL names as this venv's torch-CUDA (YOLO) and the two cannot load
# in one Windows process (WinError 127). Instead give it its own venv where torch
# is CPU-only, and the backend spawns it as a subprocess (auto-degrades to MinerU-
# only if the venv is absent). One-time setup with uv (Python 3.11, CUDA 12.6):
#   uv venv .venv_ocr --python 3.11
#   OCRPY=.venv_ocr/Scripts/python.exe
#   uv pip install --python $OCRPY torch --index-url https://download.pytorch.org/whl/cpu
#   uv pip install --python $OCRPY paddlepaddle-gpu==3.2.0 \
#       --index-url https://www.paddlepaddle.org.cn/packages/stable/cu126/ \
#       --extra-index-url https://pypi.org/simple/ --index-strategy unsafe-best-match
#   uv pip install --python $OCRPY paddleocr==3.2.0
#   uv pip install --python $OCRPY nvidia-cudnn-cu12==9.9.0.52   # match paddle's cuDNN 9.9
